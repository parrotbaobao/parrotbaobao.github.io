# Git 基本使用

Git 是一个分布式版本控制系统，用于跟踪文件的更改，尤其是程序代码。它可以帮助多人协作开发，并保持代码历史的记录。本文将介绍 Git 的一些基本命令和常见操作。

## 1. 安装 Git

首先，你需要在你的计算机上安装 Git。你可以访问 [Git 官网](https://git-scm.com/) 下载并安装。

```bash
# 在终端中输入以下命令，检查 Git 是否安装成功
git --version
```

如果 Git 安装成功，你将看到 Git 的版本信息。

## 2. Git 基本概念

*   **仓库（Repository）：** 存储项目所有文件和历史记录的地方。
*   **工作区（Working Directory）：** 你在本地计算机上编辑文件的目录。
*   **暂存区（Staging Area）：** 用于存放你想要提交的更改。
*   **提交（Commit）：** 将暂存区的更改保存到仓库的历史记录中。
*   **分支（Branch）：** 用于并行开发的不同代码版本。
*   **合并（Merge）：** 将不同分支的更改合并到一起。

## 3. Git 常用命令

### 3.1 初始化仓库

```bash
# 在项目根目录下初始化 Git 仓库
git init
```

### 3.2 添加文件到暂存区

```bash
# 添加单个文件到暂存区
git add <文件名>

# 添加所有更改的文件到暂存区
git add .
```

### 3.3 提交更改

```bash
# 提交暂存区的更改，并添加提交信息
git commit -m "提交信息"
```

### 3.4 查看仓库状态

```bash
# 查看当前仓库的状态，包括已修改但未暂存的文件，以及已暂存但未提交的文件
git status
```

### 3.5 查看提交历史

```bash
# 查看提交历史记录
git log
```

### 3.6 创建和切换分支

```bash
# 创建一个新的分支
git branch <分支名>

# 切换到指定分支
git checkout <分支名>

# 创建并切换到新的分支（常用）
git checkout -b <分支名>
```

### 3.7 合并分支

```bash
# 切换到要合并到的目标分支
git checkout <目标分支>

# 将指定分支的更改合并到当前分支
git merge <要合并的分支>
```

### 3.8 远程仓库

*   **克隆远程仓库：**

    ```bash
    git clone <远程仓库地址>
    ```
*   **添加远程仓库：**

    ```bash
    git remote add origin <远程仓库地址>
    ```
*   **推送本地分支到远程仓库：**

    ```bash
    git push origin <本地分支名>:<远程分支名>

    # 如果本地分支名和远程分支名相同，可以简写为：
    git push origin <分支名>
    ```
*   **从远程仓库拉取更新：**

    ```bash
    git pull origin <分支名>
    ```

## 4. 常见 Git 操作

### 4.1 撤销更改

*   **撤销工作区的更改：**

    ```bash
    git checkout -- <文件名>
    ```
*   **撤销暂存区的更改：**

    ```bash
    git reset HEAD <文件名>
    ```

### 4.2 解决冲突

当合并分支时，如果不同分支对同一文件进行了不同的修改，可能会发生冲突。你需要手动解决冲突，然后重新提交。

1.  打开包含冲突的文件。
2.  查找包含 `<<<<<<<`，`=======` 和 `>>>>>>>` 的部分。
3.  手动编辑文件，选择要保留的更改，并删除冲突标记。
4.  将解决冲突后的文件添加到暂存区。
5.  提交更改。
